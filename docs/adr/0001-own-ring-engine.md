# Кольца считает свой движок, а не внешний API и не Valhalla

Кольца считаем своим графом дорог от motorway до tertiary, без паромов, обходом Дейкстры на TypeScript в Cloudflare Container standard-2: на standard-1 тёплое кольцо на 12 ч считалось 3,4–24 с, дольше 3 с из спеки (замер #25, `docs/container-bench.md`). Условия задачи — закрытые страны вместе с транзитом, время на границе с нулём внутри Шенгена, пересечение границы только на пункте пропуска, правила пар стран и запас ×1,2 — проверяются прямо в обходе. Valhalla остаётся только эталоном, по которому сверяем точность.

## Рассмотренные варианты

- **Внешние API изохрон** (14 штук, ближе всех HERE). Времени на границе с исключением для Шенгена нет ни у одного. У HERE предел 9 ч, а лицензия запрещает отдавать один результат многим, то есть общий кэш колец невозможен. Подробности в тикете «Кольца через внешние API изохрон» (#3).
- **Valhalla или GraphHopper с графом всей планеты.** В Container не помещаются: тайлы весят 70–140 ГБ, а у самого большого инстанса 12 GiB памяти и 20 GB диска.
- **Valhalla на урезанном графе.** Помещается, но 12 ч из центра Европы считаются 20–60 с. Закрытые страны и правило про Шенген выражаются только обходными путями. Подробности в тикете «Свой движок маршрутов на Cloudflare» (#4).
- **Свой граф в Worker или в браузере.** Worker упирается в 128 МБ, и граф вдали от старта пришлось бы огрублять. Телефону на 12 ч нужно скачать 40–80 МБ. Движок пишем переносимым модулем, чтобы к этим вариантам можно было вернуться.

## Последствия

- Скорости по классам дорог свои, поэтому первая задача реализации — сверка с Valhalla на 20–30 точках старта с допуском ±10 % по площади кольца и медиане времени до городов.
- Граф собираем сами раз в месяц вне Container: планета весит 89 ГБ.
- Если тёплый расчёт и на standard-2 выйдет дольше 3 с, ускоряем контур: по замеру #25 он занимает ~80 % времени, а обход, который можно было бы переписать на Rust через WASM, ~20 %. Интерфейс движка при этом не меняется.

Решение принято в тикете «Как считаем кольца» (#8).
