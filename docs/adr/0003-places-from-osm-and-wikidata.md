# Места берём из OSM, известность и названия из Wikidata

Список мест (точек интереса не-городов) — объекты OSM с тегом места и тегом `wikidata=`. Их извлекает из частей Geofabrik та же ежемесячная сборка, что строит граф. Тип места даёт тег OSM. Известность — число сайтлинков элемента Wikidata по всем проектам Викимедиа из SQL-дампа `wb_items_per_site` (CC0). Русская и английская метки и точка P625 берутся из WDQS по списку Q-id, как русские метки городов в `build-cities`. Ключ места — Q-id. Так вся сборка состоит из дампов и запросов по id, без чужих сервисов с запросами по классам. Цена этого — около 23 % известных мест Wikidata, у которых в OSM нет `wikidata=`: археологические памятники, пляжи, ледники, каньоны, нацпарк Ретезат.

## Что берём

- **Тип** — тег OSM, по которому объект попал в выборку. Классы Wikidata (P31) шумные: курорт Бэиле-Еркулане записан там как археологический памятник. Wikidata служит только точечной проверкой: храм считается монастырём, только если у него Q44613.
- **Известность** — сайтлинки без поправок. Убирание бот-разделов (`ceb`, `sv`, `war`) почти ничего не меняет. QRank (просмотры за год) в запасе как второй ключ сортировки.
- **Точка.** У объекта-точки (вершина, водопад, пещера) — координата узла OSM. У контура (озеро, нацпарк, замок) — P625 Wikidata, а если её нет, точка внутри контура OSM. Контур сборка сохраняет.
- **Русское название**, по старшинству: своя таблица русских названий мест по Q-id, метка `ru` Wikidata, заголовок статьи ruwiki без уточнения в скобках. Первая буква заглавная. Пропуски в таблице дописывают Haiku-субагенты, как у городов: родовое слово переводят («озеро», «монастырь»), имя собственное транскрибируют. `name:ru` из OSM не берём, он добавляет 1 пункт покрытия.
- **Второе название** — английская метка Wikidata, иначе `name` из OSM.

## Рассмотренные варианты

- **Список из Wikidata по классам, геометрия из OSM.** Полнее на 23 %, к тому же сразу есть классы и P18. Но полный дамп весит 104 ГБ (`latest-all.json.bz2`): на диск раннера Actions он не помещается, а скачать и прочитать его за 6 ч одной джобы мы не мерили. Официальный WDQS падает на запросе класса «гора» по таймауту, а сторонний QLever отвечает 429 и ничего не обещает. Источник списка — деталь сборки: ключ Q-id, файл и таблица русских названий от него не зависят. Поэтому к дампу Wikidata, переложенному через Actions в R2, можно перейти позже, если окажется, что не хватает знакомых мест.
- **GeoNames.** Нет меры известности, покрытие перекошено к США и Норвегии.
- **Wikivoyage.** Листинги в основном городские, ранга нет, лицензия CC BY-SA с share-alike.
- **OpenTripMap.** Нет дампа, только API с ключом.

Новой строки атрибуции на экране не нужно: OSM уже указан, а данные Wikidata выложены под CC0. В `docs/attribution.md` добавлен раздел «Wikidata (CC0)» — записка о том, что берём из Wikidata и почему указывать её не обязательно (#159).
