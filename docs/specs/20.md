Сводная спека MVP по решениям карты [«Карта: куда доехать на машине за N часов с учётом виз»](https://github.com/igorkamyshev/roadtrip/issues/1). Термины — из `GLOSSARY.md`, выбор движка — в ADR 0001. Подробности и причины каждого решения — в тикете по ссылке. Если спека расходится с тикетом, прав тикет, а спеку надо поправить.

Реализация разбита на подзадачи этого тикета, #21–#37, с меткой `ready-for-agent` или `ready-for-human`. Блокировки — строкой `Blocked by:` в начале каждой подзадачи.

## Проблема

Человек едет на машине и хочет понять, куда доберётся за несколько часов. Обычные карты знают дороги, но не знают, куда его пустят: визы по его паспортам, визы, которые у него уже есть, закрытые границы, войны, разрешения на машину. Сервисы изохрон этого тоже не умеют: в них нет закрытых стран, времени на границе и исключения для Шенгена. Сейчас приходится сверять карту с правилами въезда по каждой стране и с новостями о границах, и всё равно легко проложить путь через страну, куда не пустят.

## Решение

Публичный сайт без аккаунтов, один экран, сделанный под телефон, интерфейс и подписи на карте по-русски.

- Человек задаёт точку старта геолокацией, поиском города или булавкой.
- Во фразе над картой выбирает гражданства и мои визы.
- Вертикальным ползунком выбирает N от 1 до 12 часов.

Сайт рисует кольцо — где можно оказаться за N−1…N ч в пути, ни разу не въезжая в закрытую страну или закрытую территорию. Закрытые страны заштрихованы. Под картой — карусель городов в кольце с пометкой способа въезда и кнопкой «Маршрут» в Google Картах. Время в пути = время за рулём × 1,2 + 1,5 ч на каждой границе с паспортным контролем, внутри Шенгена 0. Настройки живут в браузере и в ссылке, так что кольцом можно поделиться.

Под капотом: Cloudflare Worker на своём домене, свой движок колец в одном Cloudflare Container, визовые правила из Sherpa плюс своя таблица исключений по визе, подложка Protomaps, аналитика и ошибки в PostHog.

## Решения по реализации

### Устройство

pnpm-workspace, TypeScript. Модули:

| Модуль | Что внутри |
|---|---|
| `web` | Клиент: Vite, React, TanStack Router, TanStack Query, TanStack Virtual, MapLibre GL, `posthog-js`. Один экран. |
| `worker` | Cloudflare Worker `roadtrip` на боевом домене (`workers_dev = false`): статика клиента и данных, тайлы подложки, `GET /api/ring`, визовая модель, кэши в KV, класс Container'а с движком, `posthog-node`. |
| `engine` | Движок колец: чистый переносимый модуль без Node API, чтобы его можно было перенести в Worker или браузер (ADR 0001). Сюда же HTTP-сервер для Container'а и образ. |
| `rules` | Таблицы, которые правят руками: таблица границ, таблица исключений по визе, Шенген, ЕС, закрытые для всех, паспорта Sherpa. Схемы и проверка при сборке. |
| `data` | Месячная сборка набора данных: граф дорог, полигоны зон, файл городов, контуры стран для штриховки. Сюда же скрипт сверки с Valhalla. |
| `error-tracking` | Tail Worker, перенесённый из ytc. |

Клиент на TanStack — решение владельца. Router держит состояние экрана в параметрах ссылки, Query — запросы колец и память браузера, Virtual — длинный список городов. TanStack Start не берём: экрану не нужен SSR, а сервер — обычный Worker с классом Container'а и тайлами. Серверные функции Start ходили бы по своим путям, мимо правила WAF на `/api/*`.

У `engine` и `data` свои `AGENTS.md`: правило подъёма версии движка и устройство месячной сборки.

### Набор данных

Собирается раз в месяц в GitHub Actions (тикет [«Где собирать граф дорог»](https://github.com/igorkamyshev/roadtrip/issues/14)) и хранится в R2 по версиям. Версия — дата выгрузок Geofabrik.

- **Выгрузки.** Части света Geofabrik, кроме России, в параллельных matrix-джобах, все на одну дату. `osmium tags-filter` оставляет:
  - дороги от motorway до tertiary со съездами, без паромов;
  - узлы `barrier=border_control`;
  - границы `admin_level=2` и отношения из тикета [«Спорные территории…»](https://github.com/igorkamyshev/roadtrip/issues/13).

  Дальше `merge` и `add-locations-to-ways` в отдельной джобе.
- **Зоны.** Каждый узел графа относится к зоне: стране (alpha-3, как у Sherpa) или закрытой территории. Полигоны — из OSM, особые случаи по #13:
  - Косово — `RKS`;
  - Северный Кипр (r2514541) — `NX`;
  - Акротири и Декелия — к Кипру;
  - Приднестровье — к Молдове;
  - Крым (полигон вроде r72639) — закрытая территория, а не Россия и не Украина;
  - Абхазия (r1152720) и Южная Осетия (r1152717) — закрытые территории;
  - Газа (r1473938) — закрытая территория;
  - вся Западная Сахара (r2559126) — закрытая территория.
- **Граф.** Компактные typed arrays по замеру из `research/cloudflare-routing`: ~13 байт на узел, ~6 байт на ребро, ~0,6–0,7 ГБ на мир. Цепочки узлов степени 2 схлопнуты.
  - У ребра время за рулём: скорость по классу дороги, а если `maxspeed` меньше — по `maxspeed`. Стартовые скорости: motorway 110, trunk 90, primary 70, secondary 60, tertiary 50, съезды 30–60 км/ч. Подгоняются при сверке с Valhalla.
  - У ребра через границу — пара зон и признак «через пункт пропуска»: ребро проходит через узел `barrier=border_control` или рядом с пунктом из таблицы границ.
  - Формат — общий модуль сборщика и движка.
- **Отчёт сборки:** пары стран с паспортным контролем, где не нашлось ни одного пункта пропуска, — чтобы дополнить таблицу вручную.
- **Файл городов.** GeoNames `cities1000` (CC BY 4.0) от 15 000 жителей, без PPLX и исчезнувших мест, ~31 800 городов. Для каждого города:
  - id GeoNames;
  - русское название из GeoNames, а если его нет — из Wikidata по P1566;
  - местное название;
  - координаты и население;
  - зона по нашим полигонам, а не код GeoNames: так города Северного Кипра получают `NX`.

  ≈0,6 МБ в brotli, отдаётся статикой Worker'а.
- **Контуры зон для штриховки.** Полигоны стран и закрытых территорий, упрощённые до ~2 км, порядка 1 МБ в brotli. Тоже статика.
- **Выкладка.** Набор кладётся в R2 под своей версией, указатель «текущая версия» переводится на него. Затем месячная сборка через API Cloudflare запускает сборку `roadtrip` в Workers Builds.
- **Деплой** — Cloudflare Workers Builds, как у воркеров ytc. Руками ничего не деплоится.
  - На пуш в `main` триггер каждого воркера запускает `pnpm --filter <модуль> run deploy` с пустой командой сборки. Скрипт `deploy` делает весь деплой.
  - Скрипт `deploy` у `worker` берёт текущий набор из R2, кладёт граф в образ Container'а (из R2 при каждом холодном старте граф грузился бы ~15 с), файл городов и контуры зон — в статику, собирает клиент и запускает `wrangler deploy`. Сборку Container'а не минифицируем.
  - Воркеры и триггеры заводит агент через API Cloudflare (коннектор Cloudflare в AIP), как в разделе «A new worker» инфраструктурной доки ytc. Сначала `roadtrip-error-tracking`, потом `roadtrip`. Секреты задаёт владелец.

Чтение 10–15 ГБ PBF в JS может оказаться медленным. Тогда шаг чтения заменяется на pyosmium, а формат графа остаётся тем же.

### Таблица границ

Файл в `rules`, правится руками. Читает его движок, а его хэш входит в версию данных. Основа — тикет [«Закрытые сухопутные границы»](https://github.com/igorkamyshev/roadtrip/issues/5) с поправками #13.

- **Пары стран** (неупорядоченные, alpha-3). Статусы:
  - `closed` — граница закрыта;
  - `no_crossing` — дорожного перехода нет;
  - `pedestrian_only` — только пешком;
  - `crossings_only` — открыты только пункты из списка;
  - `no_control` — без паспортного контроля, 0 ч.

  Плюс необязательное своё время на границе, дата проверки, источники и заметки. Статусов `one_way`, `closed_except` и `permit_only` нет: по #13 границ в одну сторону и правил «только для граждан» нет. Где граница зависит от гражданства, считаем как для гражданина России: RUS–BLR — 0 ч для всех, TUR–SYR закрыта, пункт Кайрагач (KGZ–TJK) закрыт, IND–NPL — 1,5 ч.
- **Пункты пропуска:** id, пара, название, координаты, необязательный id OSM, статус (`open`, `closed`, `pedestrian_only`), дата проверки, источники. Это белый список для пар `crossings_only` (POL–BLR, EST–RUS и т. д.) и точечные закрытия в открытых парах: Псоу, Рокский тоннель, переходы Украины с Приднестровьем, Нарва для машин. Координаты в исследовании не заполнены — их заполняет первая задача по данным.
- **Закрыто для всех.** Страны UKR, RKS, AZE, CHN, MMR, BTN и закрытые территории. Строки пар с этими странами в таблице не нужны.
- **Шенген** — 29 государств плюс MCO, SMR, VAT и GIB. Внутри него время на границе 0, проезд по любой дороге.
- **Время на границе по умолчанию** — 1,5 ч.

### Визовые правила и сведение

По тикету [«Как загружаем и кэшируем визовые правила»](https://github.com/igorkamyshev/roadtrip/issues/11).

- **Sherpa.** `POST /v3/maps` с телом `{"data":{"type":"MAP","attributes":{"passportCode":"<X>"}}}`, заголовки `x-api-key` и `content-type: application/vnd.api+json`. Ключ — секрет Worker'а `SHERPA_API_KEY`. Один запрос на гражданство, ~230 стран в 7 группах. Запасного пути через `/v3/trips` нет.
- **Проверка ответа.** Ответ проходит проверку по схеме, и в нём должно быть не меньше 200 стран. Иначе это сбой `bad_response`. Таймаут запроса — 10 с.
- **Кэш в KV**, ключ — гражданство. В значении только «страна → класс» и время загрузки.
  - Копия свежая сутки.
  - Устаревшая копия отдаётся сразу, а новая грузится в фоне через `waitUntil`.
  - Копии нет — ждём загрузки.
  - Последнюю удачную копию не удаляем никогда.
  - После неудачи следующая попытка по тому же гражданству — не раньше чем через 15 мин. Отметка неудачи живёт в KV с TTL.
- **Классы Sherpa → способ въезда:**
  - `NO_VISA_REQUIRED` — без визы;
  - `VISA_ON_ARRIVAL_REQUIRED` — виза по прибытии;
  - `EVISA_OR_ETA_REQUIRED` — электронная виза;
  - `PAPER_OR_EMBASSY_VISA_REQUIRED`, `RESTRICTED_ENTRY`, `UNKNOWN_*` и отсутствие в ответе — закрыта, если её не открывают мои визы.
- **Таблица исключений по визе** — файл в `rules` из исследования `research/visa-exemptions`. Поля строки:
  - страна назначения;
  - чья виза открывает: `SCHENGEN`, `USA`, `GBR` или `CAN`;
  - что даёт: без визы или электронную визу;
  - необязательная дата окончания: после неё строка не действует, сравниваем с сегодняшней датой UTC;
  - необязательный список гражданств, к которым применяется строка;
  - условия текстом — только для людей: «многократная», «уже использованная» и требование ВНЖ не проверяем, берём лучший случай;
  - источник и дата проверки.

  Тексты исключений из Sherpa (`more[]`) не разбираем.
- **Сведение** — одна чистая функция в `worker`. На входе классы Sherpa по каждому гражданству, мои визы, таблица исключений, списки Шенгена и «закрыто для всех», сегодняшняя дата. На выходе по каждой стране способ въезда и откуда он взялся. Правила по порядку:
  1. Страна, закрытая для всех, закрыта всегда.
  2. Страна любого из гражданств открыта без визы.
  3. Иначе берём лучший способ среди гражданств и моих виз в порядке: без визы, по моей визе, виза по прибытии, электронная виза, иначе закрыта.
     - Моя виза страны открывает саму страну.
     - «Шенген» открывает весь Шенген.
     - Действующие строки таблицы исключений открывают страну, если их виза есть среди моих виз, а список гражданств строки пуст или пересекается с моими гражданствами. Строка «без визы» даёт способ «по моей визе», строка с электронной визой — «электронную визу».
- **Страна точки старта.** Сведение её не знает: её определяет движок. Worker после ответа движка помечает страну старта открытой («страна старта»), если она закрыта по визам, но не закрыта для всех.
- **Набор закрытых стран** — коды стран, закрытых по итогам сведения, без поправки на страну старта.
- **Код Шенгена** в моих визах, ссылке и событиях — `SCHENGEN`. Шенген выбирается только целиком.
- **Гражданства** выбираются только из 199 паспортов, которые знает Sherpa. Список лежит в `rules`.

### API кольца

`GET /api/ring` — единственный эндпоинт Worker'а для клиента. Запросы к `/api/*` считает правило WAF.

- **Вход:**
  - `lat`, `lon` — исходная точка старта, без округления;
  - `hours` — N от 1 до 12;
  - `cit` — отсортированные alpha-3 из списка паспортов, минимум один;
  - `visas` — отсортированные коды: `SCHENGEN` и alpha-3 вне Шенгена, может быть пусто.

  Неверный вход — 400.
- **Ответ 200**, JSON:
  - `outcome`:
    - `ring` — кольцо есть;
    - `empty` — кольцо N пустое, дальше не уехать;
    - `no_roads` — дорога дальше 50 км;
    - `no_ring` — старт в стране или на территории, закрытой для всех;
    - `visa_rules_missing` — нет визовых правил по гражданству;
  - `ring` — GeoJSON MultiPolygon с дырами, только для `ring`;
  - `maxHours` — для `empty`: наибольшее время в пути, до которого можно доехать, округлённое вверх;
  - `startCountry`;
  - `access` — способ въезда по каждой стране (`visa_free`, `held_visa`, `visa_on_arrival`, `evisa`, `start`, `closed`), откуда он взялся (гражданство или моя виза) и признак «закрыта для всех»;
  - `visaRulesLoadedAt` — время загрузки самой старой из копий по гражданствам;
  - `missingCitizenship` — для `visa_rules_missing`;
  - `source` — `cache`, `calculation` или `joined`.
- **Ошибки.** 5xx — сбой Container'а или Worker'а. 429 отдаёт сам Cloudflare по правилу WAF.
- **Порядок работы Worker'а:**
  1. Проверить вход.
  2. Получить визовые правила. Если нет копии хотя бы по одному гражданству — `visa_rules_missing`.
  3. Свести их и получить набор закрытых стран.
  4. Округлить точку до сетки 0,001°.
  5. Собрать ключ и прочитать KV. Попадание — ответ без Container'а.
  6. Промах — запрос в Container.
  7. Записать кольцо в KV, применить страну старта к `access` и ответить.

### Кэш колец

По тикету [«Лимиты расчётов и кэш колец»](https://github.com/igorkamyshev/roadtrip/issues/15) с поправкой #13: гражданства в ключ не входят.

- **Ключ:** версия данных, точка старта, округлённая до 0,001° ещё до привязки к дороге, N и SHA-256 отсортированного набора закрытых стран. Хэш нужен, потому что сам набор может быть длиннее предела ключа KV в 512 байт.
- **Версия данных:** версия набора данных, хэш таблицы границ и номер версии движка. Номер поднимаем руками, когда меняется результат: скорости, ×1,2, построение контура, формат ответа.
- **Расчёт получает только поля ключа.** Container возвращает версии, по которым считал. Если они не совпали с версиями Worker'а (идёт выкатка), кольцо отдаётся, но в KV не пишется. Так старый движок не подложит кольцо под новый ключ.
- **Хранение.** Workers KV, `expirationTtl` 40 дней. Кольцо больше 25 МиБ не кэшируем. Кэшируются все исходы движка: `ring`, `empty`, `no_roads`, `no_ring`.
- **Без ручной чистки.** Смена версии данных — новое пространство ключей, старое истекает само. Смена визовых правил трогает только кольца, у которых поменялся набор закрытых стран.

### Container и очередь

- **Настройки:** `instance_type: "standard-1"` явно, `max_instances: 1`, политика размещения `default`, `sleepAfter` по умолчанию (10 мин). `portReadyTimeoutMS` поднят, чтобы успел загрузиться граф. Точное значение — по замеру холодного старта.
- **Сервер в образе** загружает граф и таблицу границ при старте и считает по одному кольцу. Остальные запросы ждут по порядку, без таймаута. Запрос с ключом, который уже считается, ждёт тот же результат и получает `joined`.
- **Ответ:** исход, контур, `maxHours`, страна старта, версии и тайминги — ожидание в очереди, обход, построение контура и холодный старт, если запрос его ждал. При сбое — 500 с `{ name, message, stack }`.

### Движок

По тикету [«Как считаем кольца»](https://github.com/igorkamyshev/roadtrip/issues/8) и ADR 0001. Интерфейс: граф, таблица границ, точка старта (уже округлённая), N и набор закрытых стран → исход, контур, `maxHours`, страна старта, тайминги.

- **Страна старта** — зона, где стоит точка. Для точки в море — зона дороги, к которой она привязана.
- **Если страна старта закрыта для всех** или точка в закрытой территории — `no_ring`.
- **Страна старта открыта** даже при совпадении с набором закрытых стран.
- **Привязка:**
  - точка на суше привязывается к ближайшей дороге графа в стране старта, точка в море — к ближайшей дороге в любой стране;
  - путь до дороги — по прямой со скоростью 30 км/ч, он прибавляется ко времени за рулём;
  - дорога дальше 50 км — `no_roads`.
- **Обход** — Дейкстра по времени в пути до N часов:
  - ребро стоит своё время за рулём × 1,2;
  - вход в узел закрытой страны или закрытой территории запрещён;
  - на ребре через границу двух открытых стран:
    - пары `closed`, `no_crossing`, `pedestrian_only` непроезжие;
    - у пары `crossings_only` проезжие только рёбра у открытых пунктов из таблицы;
    - рёбра у точечно закрытых пунктов непроезжие;
    - если обе страны в Шенгене или пара `no_control`, проезд по любой дороге за 0 ч (или за своё время пары);
    - иначе только рёбра через пункт пропуска, плюс время на границе (1,5 ч или своё время пары).
- **Кольцо** — область, где время в пути в (N−1, N]:
  - строим растром с шагом ~500 м и marching squares, как Valhalla;
  - ячейки далеко от достигнутых дорог и ячейки в закрытых зонах в кольцо не входят;
  - контур упрощаем до ~500 м.

  Кольца 1…N−1, попутно видные при обходе, не сохраняем.
- **Пустое кольцо.** Если ни одна точка не достигнута позже N−1, ответ `empty` с `maxHours`.
- **Цель по скорости** — до 3 с на кольцо в 12 ч у тёплого Container'а. Если дольше, сначала берём standard-2, потом переписываем цикл обхода на Rust через WASM. Интерфейс движка при этом не меняется.

### Экран

Вариант C «Фраза и карусель» из тикета [«Экран на телефоне»](https://github.com/igorkamyshev/roadtrip/issues/10). Первоисточник по вёрстке и текстам — прототип в ветке `claude/you-mshpw6` (`#c`). Где решения молчат, прав прототип. На десктопе тот же экран, отдельной вёрстки нет.

- **Фраза над картой:** «Из точки [Белград], 2–3 часа в пути. Гражданство [РФ], мои визы: [нет] ⓘ». Каждое слово в скобках открывает шторку. Отдельного экрана настроек нет.
  - Подпись точки старта: город из поиска — его название, булавка — «на карте», геолокация, ссылка и сохранённые настройки — ближайший город из файла городов. Без точки — мигающее «выберите».
  - Пока идёт расчёт, рядом с часами крутится индикатор.
  - Под фразой строка «визовые правила от <дата>», если `visaRulesLoadedAt` старше двух суток.
- **Шторка «Откуда едем»:**
  - поиск по началу русского или местного названия, регистр и ё не важны, до 8 результатов, сначала совпадения с начала, крупные выше;
  - пустой результат — «Такого города нет в списке. В нём города от 15 000 жителей.»;
  - кнопки «Указать на карте» и «Где я», под ними пометка, если браузер не дал геолокацию.
- **Шторка «Гражданство»:** несколько, минимум одно, фильтр по названию, «по умолчанию» у российского. Пояснение: «Можно несколько: для каждой страны берём самый удобный вариант въезда.»
- **Шторка «Мои визы»:**
  - сверху раздел «Шенген и визы, которые открывают другие страны»: Шенген, США, Великобритания, Канада с подписью, сколько стран открывают по действующим строкам таблицы (например «Открывает весь Шенген и ещё 10 стран, например Черногорию и Косово»);
  - ниже «Виза одной страны» — все страны вне Шенгена, с фильтром.

  Названия стран по-русски: `Intl.DisplayNames('ru')` по alpha-2 плюс свои названия для `RKS` и `NX`.
- **Булавка.** «На карте» включает режим булавки: «Двигайте карту, чтобы поставить точку под булавку», кнопки «Отмена» и «Старт здесь». Тапом и долгим нажатием по карте точку не ставим.
- **Ползунок** вертикальный, у правого края карты, 1–12 ч: столбик из 12 ячеек, снизу 1 ч. Ячейка — кольцо N−1…N. Выбранная ячейка синяя и подписана отрезком («до 1», «6–7»), остальные — числом N. Тап по ячейке выбирает её, при перетаскивании выбрана ячейка под пальцем. Кольцо запрашивается, когда ползунок отпущен. Часы, кольца для которых уже получены при текущих точке и настройках, отмечены светло-зелёной ячейкой. Здесь экран отходит от прототипа, где была дорожка с кружком (#44).
- **Карта.** MapLibre GL со стилем `@protomaps/basemaps`, подписи `coalesce(name:ru, name)`, шрифты и спрайты Protomaps из нашей статики. Тайлы `/tiles/{z}/{x}/{y}` отдаёт Worker из мирового PMTiles в R2 с `Cache-Control` дольше суток. Атрибуция — строка источников из ⓘ (ниже): при открытии экрана она 5 с стоит под фразой, потом остаётся только в ⓘ. Так требуют правила атрибуции OSM: атрибуцию видно без нажатия, свернуть её можно только после показа (#46, `docs/attribution.md`). Своей кнопки атрибуции у MapLibre нет. Поверх подложки:
  - закрытые страны и закрытые территории — штриховка по `access` и контурам зон;
  - кольцо;
  - маркер точки старта;
  - подписи городов из карусели, у выбранного — выделение.
- **Старое кольцо при расчёте.** Пока идёт расчёт, старое кольцо той же точки старта остаётся с бегущей полосатой заливкой. По новому кольцу карта показывает его целиком, с отступами под фразу и карусель.
- **Города в кольце** отбирает телефон:
  - точка города внутри мультиполигона кольца;
  - зона города открыта по `access`;
  - город не в закрытой территории.

  Сортировка по населению.
- **Карусель:**
  - первая карточка — сводка или состояние;
  - дальше 12 крупнейших городов;
  - последняя карточка — «и ещё K / Все города →», открывает шторку со всеми городами. Список в ней виртуальный (TanStack Virtual): в кольце на 12 ч бывают тысячи городов;
  - листание ведёт карту к городу, тап по подписи города на карте листает карусель к его карточке, а если его нет среди 12 — открывает полный список.
- **Карточка города** проектируется под любую точку интереса. На ней:
  - название, а под ним местное название, если русского нет или оно другое;
  - страна, население («1,2 млн», «85 тыс.»);
  - пометка: электронная виза — «оформить заранее», виза по прибытии — «виза на границе», моя виза — «по визе Шенгена» или «по визе: <страна>», страна старта — «страна старта», без визы — без пометки;
  - строка «Российские номера не пустят», если город в стране ЕС, а среди гражданств есть российское;
  - кнопка «Маршрут»: Google Карты `dir/?api=1&origin=<старт>&destination=<город>&travelmode=driving`.
- **Первая карточка, по состояниям:**

  | Состояние | Текст | Кнопки |
  |---|---|---|
  | нет точки старта | «Откуда едем?» + «Найдите город или укажите точку на карте» (и «Браузер не дал доступ к геолокации», если так) | «Город», «На карте», «Где я» |
  | расчёт | «Кольцо 2–3 ч», «Считаем…», бегущая полоса; через 5 с — «Чуть дольше обычного, досчитываем — подождите» | — |
  | кольцо | «В кольце 2–3 ч», число городов, «в K странах», «Листайте → самые крупные» | — |
  | `empty` | «Дальше M ч не уехать», «Дальше море или закрытые страны. Добавьте свои визы или уменьшите время.» | «Мои визы» |
  | нет городов | «Городов в кольце нет», «Показываем города больше 15 000 жителей.» | — |
  | `no_roads` | «Рядом нет дорог», «Точка дальше 50 км от дороги. Выберите другую.» | «Город», «На карте» |
  | `no_ring` | «Кольца нет», «Отсюда посчитать не можем: эта страна или территория закрыта для всех.» | «Город», «На карте» |
  | `visa_rules_missing` | «Не удалось загрузить визовые правила для гражданства <X>. Попробуйте позже или уберите это гражданство» | «Гражданство» |
  | 429 | «Слишком много запросов, подождите несколько секунд» | «Повторить» |
  | 5xx или сеть | «Не получилось посчитать», «Проверьте интернет и попробуйте ещё раз.» | «Повторить» |

- **ⓘ «Что важно знать»:**
  - «В страны ЕС не пускают машины с российскими номерами. Если едете на такой машине, страны ЕС в кольце вам не подходят.»
  - «Визовые правила — по данным Sherpa и нашей таблицы исключений. Они меняются: перед поездкой проверьте правила въезда. Условия вроде многократной или уже использованной визы мы не проверяем.»
  - «Маршрут строят Google Карты. Они не знают, какие страны для вас закрыты, и могут повести через них. За их маршрут мы не отвечаем.»
  - «Время в пути — время за рулём ×1,2 и по 1,5 ч на каждой границе с паспортным контролем.»
  - «Источники данных: OpenStreetMap, GeoNames (CC BY 4.0, с изменениями), Protomaps, ESA WorldCover (CC BY 4.0), Sherpa.» Каждое название — ссылка, OpenStreetMap ведёт на `openstreetmap.org/copyright`, «CC BY 4.0» — на лицензию. ESA WorldCover — растительность на подложке Protomaps; «с изменениями» — файл городов отбирает и переименовывает места GeoNames (#46).

  Время в пути до города на карточке не показываем (тикет #19).

### Состояние, ссылка и память браузера

- **Маршрут.** Один маршрут TanStack Router с хэш-историей, поэтому всё состояние ссылки живёт в `#…`, как решено в #18. Пример: `/#/?p=44.81760,20.45730&h=3&cit=RUS,SRB&visas=SCHENGEN`.
  - В параметрах — точка старта, N, гражданства и мои визы. Они описаны схемой и проверяются при входе (`validateSearch`): неверное значение заменяется значением по умолчанию.
  - Каждое изменение — `navigate` с `replace: true`, чтобы не копить историю браузера. Тот же снимок сохраняется в `localStorage`.
  - Шторки, режим булавки и выбранная карточка в ссылку не попадают.
- **При загрузке:**
  - если в `#…` есть состояние, берём его;
  - иначе сохранённое, и оно подставляется в ссылку;
  - иначе по умолчанию: RUS, моих виз нет, N = 1, точка старта по геолокации.

  Открытая ссылка становится текущим состоянием и перезаписывает сохранённое.
- **Запросы колец — TanStack Query.** Ключ запроса — точка, N, гражданства и мои визы.
  - `staleTime` и `gcTime` бесконечные: полученный ответ живёт в памяти до конца сессии и показывается без запроса (`source: memory`).
  - Отмеченные часы на ползунке — часы, для которых в кэше Query есть ответ при текущих точке и настройках.
  - Автоповторов нет: «Повторить» вызывает `refetch`.
  - Пока идёт новый запрос, `placeholderData` отдаёт прежнее кольцо, если точка старта та же: оно рисуется с бегущей полосатой заливкой.
  - Функция запроса не передаёт `signal` в `fetch`. Если человек сменил запрос, не дождавшись ответа, старый ответ на экран не выводится, но попадает в память.

### Аналитика и ошибки

По тикетам [#16](https://github.com/igorkamyshev/roadtrip/issues/16), [#17](https://github.com/igorkamyshev/roadtrip/issues/17) и [#18](https://github.com/igorkamyshev/roadtrip/issues/18). PostHog — новая организация в US, отдельный проект.

- **Браузер.** `posthog-js` инициализируем только на боевом хосте:
  - `defaults: '2026-08-30'`, `capture_exceptions: true`, `disable_session_recording: true`;
  - `api_host` — поддомен управляемого прокси, `ui_host: 'https://us.posthog.com'`;
  - `tracing_headers: [<боевой домен>]`, чтобы запросы к API несли `X-POSTHOG-*`.

  Стандартная веб-аналитика и автосбор — как по умолчанию. Source maps загружает `@posthog/rollup-plugin` в сборке Vite, релиз — git SHA. Персональный ключ `phx_` — только в секретах сборки Workers Builds. Если холст MapLibre шумит `$dead_click` и `$rageclick`, ставим классы `ph-no-deadclick` и `ph-no-rageclick`.
- **Свои события браузера** (пока ползунок двигают, событий нет):

  | Событие | Когда | Свойства |
  |---|---|---|
  | `start set` | точка старта задана любым способом, в том числе при загрузке | `method` (`geolocation`, `search`, `pin`, `link`, `saved`), `start_country`, `start_city`, `start_city_id` |
  | `geolocation failed` | геолокация не сработала | `reason` (`denied`, `unavailable`, `timeout`) |
  | `ring result` | ровно одно на каждый запрос кольца | `outcome` (`ring`, `empty`, `no_roads`, `no_ring`, `visa_rules_missing`, `too_many_requests`, `error`, `abandoned`), `hours`, `citizenships`, `held_visas`, `start_country`, `start_city`, `start_city_id`, `source` (`memory`, `cache`, `calculation`, `joined`), `wait_ms` (у `memory` 0), `cities_count`, `countries_count` |
  | `link opened` | при загрузке в `#…` есть состояние, а сохранённого нет | — |

  `abandoned` уходит через `sendBeacon`, если человек ушёл со страницы, или сразу, если он сменил запрос. Место — только ближайший город из файла городов (`start_city` — русское название, иначе латиница; `start_city_id` — id GeoNames) и его страна. Коды стран — alpha-3, Северный Кипр — `NX`, Шенген — `SCHENGEN`, списки отсортированы.
- **Worker.** `posthog-node` (сборка под `workerd`, без `nodejs_compat`):
  - клиент на каждый запрос с `flushAt: 1` и `flushInterval: 0`;
  - `captureImmediate` в `ctx.waitUntil`, в конце `shutdown()`;
  - у всех событий `$process_person_profile: false`;
  - `distinct_id` и `$session_id` из заголовков `X-POSTHOG-*`, а без них `distinct_id` — `server`;
  - на небоевом хосте `disabled`.

  | Событие | Когда | Свойства |
  |---|---|---|
  | `ring served` | каждый запрос кольца, дошедший до Worker'а | `source` (`cache`, `calculation`, `joined`), `outcome`, `hours`, `duration_ms`; для `calculation` и `joined` — ожидание в очереди, обход, построение контура и холодный старт, если был |
  | `sherpa fetched` | каждый запрос к Sherpa | `citizenship`, `result` (`ok`, `http_error`, `timeout`, `bad_response`), `status`, `duration_ms`, `mode` (`background`, `blocking`); остаток квоты, если Sherpa отдаёт его в заголовке |

  Worker место не шлёт вообще.
- **Ошибки сервера** — через Tail Worker `error-tracking`, перенесённый из ytc и подключённый в `tail_consumers`.
  - Код пишет `logger.error(message, error, context)`, `captureException` не используем.
  - Сбой Sherpa — класс `SherpaError` с `reason` (HTTP-статус, `timeout`, `bad_response`) и контекстом `citizenship` и `served` (`stale` или `error`). Пишется и тогда, когда человек получил старую копию.
  - Ошибку Container'а Worker получает ответом 500 и логирует с её `name`, `message` и `stack`.
  - В `context` кладём `distinct_id` и `session_id` из заголовков браузера. Перенесённый Tail Worker берёт из них `distinct_id` и `$session_id`: в ytc он этого не делает.

## Решения по тестам

**Хороший тест** идёт через публичный интерфейс шва и проверяет внешнее поведение: что увидел человек, что ответил API, какое кольцо дал движок, какие события ушли. Подменяются только внешние границы: Sherpa, KV, PostHog, время, геолокация, сеть. Ожидаемые значения берутся из спеки или посчитаны руками на примере, а не тем же способом, что в коде. Например, ребро 60 км по дороге 60 км/ч — это 1 ч за рулём, то есть 1,2 ч в пути. Упавший тест чинят, а не удаляют и не пропускают. Как в `CODING_STANDARDS.md` ytc, раздел Tests.

Три шва (согласовано с владельцем):

1. **Движок.** Функция «граф, таблица границ, точка, N, закрытые страны → результат» без Worker'а и Container'а.
   - **Фикстуры:** крошечные OSM-файлы — десятки узлов, несколько стран и полигонов. Их собирает тот же шаг `data`, что и мир, так что заодно проверяется сборщик: зоны, пары у рёбер, признак пункта пропуска.
   - **Что проверяем:**
     - ×1,2;
     - 1,5 ч на границе и своё время пары;
     - 0 ч в Шенгене и у `no_control`;
     - граница с паспортным контролем — только через пункт пропуска;
     - `crossings_only` с белым списком, точечные закрытия, закрытые пары;
     - закрытая страна не пропускает транзитом к открытой за ней;
     - закрытая территория непроходима;
     - страна старта открыта, хотя она в наборе;
     - старт в стране, закрытой для всех, и в закрытой территории — `no_ring`;
     - дальше 50 км — `no_roads`;
     - точка в море привязывается к дороге другой страны;
     - 30 км/ч до дороги;
     - `empty` и `maxHours`;
     - кольцо содержит точки с временем в (N−1, N] и не содержит остальных;
     - контур не заходит в закрытые зоны;
     - одинаковый вход — одинаковый результат.
2. **API кольца.** Обработчик Worker'а `GET /api/ring` с зависимостями через `deps`:
   - Sherpa — подменённый `fetch`;
   - KV — двойник в памяти со сроками по подменённым часам;
   - PostHog и логгер — записывающие двойники;
   - Container — по умолчанию настоящий движок в том же процессе на графе-фикстуре, а для сбоя, очереди и `joined` — двойник.

   Правила границ здесь не повторяем: их держит шов движка. Проверяем:
   - перевод классов Sherpa в способы въезда;
   - лучшее среди гражданств, мои визы, Шенген целиком;
   - строки исключений: срок, фильтр по гражданствам, электронная виза;
   - страна гражданства открыта, закрытые для всех закрыты всегда;
   - страна старта в `access`;
   - `visa_rules_missing` и `visaRulesLoadedAt`;
   - кэш Sherpa: сутки, фоновое обновление, 15 мин после сбоя, ответ меньше 200 стран не затирает копию, удачная копия не удаляется;
   - кэш колец:
     - округление до 0,001°;
     - разные гражданства с одним набором закрытых стран получают одно кольцо из кэша;
     - новая версия данных — промах;
     - несовпадение версий — без записи;
     - больше 25 МиБ — без записи;
   - все `outcome` и 400 на неверный вход;
   - свойства `ring served` и `sherpa fetched`;
   - `logger.error` с нужным классом и контекстом.
3. **Экран.** Собранный клиент в Playwright, Chromium из окружения.
   - **Подмены:**
     - `/api/ring` и тайлы — через перехват запросов;
     - геолокация — разрешения контекста;
     - время — `page.clock`;
     - PostHog — перехват запросов к прокси.

     Экран читаем по DOM и запросам, карту — по данным её источников (кольцо, штриховка), а не по пикселям.
   - **Что проверяем:**
     - первый заход с геолокацией и без неё;
     - поиск и булавка;
     - отпускание ползунка даёт ровно один запрос;
     - память браузера: отмеченные часы на ползунке, без запроса;
     - «Считаем…» и через 5 с «досчитываем»;
     - все строки таблицы состояний;
     - строка «визовые правила от <дата>»;
     - карусель из 12 и «Все города»;
     - пометки способа въезда и строка про номера;
     - тексты за ⓘ;
     - `#…` туда и обратно, неверные параметры ссылки, сохранённые настройки, приоритет ссылки;
     - события `start set`, `geolocation failed`, `link opened`, `ring result` с `outcome`, `source`, `wait_ms`, в том числе `abandoned`;
     - один `$pageview` на загрузку и нет `#…` в `$current_url`.

**Свои тесты у Tail Worker'а.** Он сохраняет тесты из ytc («`TraceItem` → события PostHog»), плюс новые на `distinct_id` и `$session_id` из контекста.

**Сверка с Valhalla** — разовый скрипт в `data`, не тест CI:

- 20–30 точек старта (Европа, Кавказ, Турция, Средняя Азия, Америка);
- кольца на 1, 3, 6 и 12 ч;
- допуск ±10 % по площади и по медиане времени до городов;
- если не укладываемся — подгоняем скорости;
- отчёт — в PR.

**Образцы:** тесты ytc — `error-tracking` (чистое преобразование на входе и выходе), `telegram-bot` (зависимости через `deps`, e2e-обвязка с подменённым сервером); `lint/agents-pointers.test.ts` здесь же. CI (`checks.yml`) гоняет все три шва на каждый пуш, Chromium для Playwright ставится в CI.

## Вне рамок

- Ночёвки, многодневные поездки, пробки, время суток, дата поездки.

- Тревоги по ошибкам и метрикам, объём событий и план PostHog — владелец настраивает сам.
- Запись сессий.
- Точки интереса кроме городов. Карусель и карточка уже готовы под них.
- Время в пути до точки на карточке.
- Маршрут в обход закрытых стран: только предупреждение про Google Карты.

- Доступность из России: ничего не меняем и не предупреждаем.
- Аккаунты, другие языки, отдельная вёрстка для десктопа.
- Автоматическая сверка таблицы границ: она правится руками.
- Регулярное обновление подложки: мировой PMTiles заливаем один раз и обновляем вручную.
