## Как идёт прогон

Workflow `.github/workflows/dataset.yml`, подробности — в разделе «The world build» файла `data/AGENTS.md`.

1. `plan` выбирает дату: самую новую, на которую у каждой части света есть выгрузка с датой в имени (`europe-261107.osm.pbf`). Geofabrik хранит выгрузки на 1-е число месяца несколько месяцев, остальные — неделю. Версия набора — эта дата.
2. `extract` — по джобе на часть света, без России: остальные части покрывают её целиком (#14). Джоба качает часть этой даты, сверяет MD5 и дату данных в заголовке и оставляет `osmium tags-filter` дороги motorway…tertiary со съездами, `barrier=border_control` и `admin_level=2` с членами, а `osmium getid -r` — отношения #13 (`SPECIAL_ZONES` в `data/src/zones.ts`). Паромов фильтр не берёт: у них нет `highway`, а сборщик ещё и отбрасывает `route=ferry`.
3. `build` склеивает части `osmium merge` (части одной даты, поэтому у объекта одна версия; иначе джоба падает), ставит координаты на пути `osmium add-locations-to-ways --ignore-missing-nodes` и собирает граф, контуры зон и отчёт (`build-graph --outlines --report`), потом файл городов (`build-cities --report`, который дописывает в отчёт части города и города без русского названия, которых нет в таблице `data/russian-names.tsv`). Отчёт сборки — в сводке прогона.
4. `places` (спека #154, раздел «Места» ниже) склеивает выборки мест частей и собирает файл мест и клетки контуров (`build-places --report`) на графе и файле городов из `build`. Её падение набор не останавливает.
5. `publish` кладёт набор в R2 вместе с файлом мест и клетками и переводит указатель. Если джоба мест упала, версия получает места текущей версии, а отчёт сборки об этом пишет.

Прогон с частью частей света — пробный: он кладёт набор под `trials/<id прогона>/` и в конце удаляет. Из облачной сессии пробный прогон запускает пуш в ветку, кроме `main`, с правкой `.github/dataset-trial.json` (`parts`, при желании `date` и `parts_run_id`); такой прогон пробный при любых частях и ничего не деплоит. Чтобы пересобрать набор без скачивания мира, есть `parts_run_id`: джобы `build` и `places` берут отфильтрованные части из артефактов другого прогона (они хранятся 2 дня).

## Места

Джоба `places` (#159) собирает места на тех же выгрузках, что граф и города.

- **Выборка.** В `extract` к фильтру дорог добавлены два `osmium tags-filter` по исходной части: сначала объекты с `wikidata=` со всеми их членами и узлами, потом из них — объекты с тегами 11 типов мест (`TYPE_TAGS` в `data/src/places.ts`). Два фильтра подряд, потому что один фильтр оставляет объект с любым из тегов, а нужно «и то, и другое». Остальное (`water=lake` у `natural=water`, Q44613 у храмов, порог сайтлинков) проверяет `build-places`. Выборка — отдельный артефакт `osm-places-<часть>` рядом с дорогами.
- **Сборка.** `build-places` на склеенной выборке, графе и файле городов, с дампом сайтлинков Wikidata `wb_items_per_site` (≈2 ГБ, качается каждый раз) и WDQS. Файл мест, клетки контуров и раздел «Места» отчёта — в артефакте `places-<версия>` и в сводке прогона.
- **Выкладка.** В R2 — `places.json` и `place-outlines.tsv`: все клетки одним файлом, строка на клетку (`<клетка>\t<её файл>`), потому что деплой читает R2 через API Cloudflare, а тот отвечает на 1200 запросов за 5 минут. `fetch-dataset` раскладывает его обратно в `web/public/data/place-outlines/`, по файлу на клетку. Набор без файла мест деплой терпит: экран тогда показывает одни города.
- **Падение.** Если джоба мест упала (бюджет файла мест, Wikidata, больше 19 000 клеток), `publish` всё равно выкладывает набор с `--places-failed`: версия получает `places.json` и `place-outlines.tsv` текущей версии копией в бакете, а в `report.md` версии — раздел «Места» с этим. У городов так не делаем: без них сборка падает.
- **Число файлов статики.** Worker отдаёт не больше 20 000 статических файлов. Своих у клиента около сотни (98 в `web/dist` без данных), данных — `zones.json`, `cities.json`, `places.json` и клетки. Файл есть у каждой клетки 1°×1°, которой касается место: контуром, если оно от `MIN_OUTLINE_METERS` поперёк (и не больше `MAX_SQUARE_KM`), иначе радиусом вокруг своей точки (`placeRadius`). Место не дальше `MAX_ACCESS_METERS` от дороги, так что клеток не больше, чем клеток суши вне Антарктиды: ~135 млн км² по ~10 тыс. км² на клетку в средних широтах плюс прибрежные — около 17 000. С мелкими местами — вершинами, водопадами, замками, монастырями — файл будет почти у каждой клетки суши с дорогами и известным местом: в Европе почти у всех её ~1300 клеток, в мире ожидаем порядка 10 000. Джоба мест падает при больше чем 19 000 клетках — выше верхней оценки и ниже предела Worker'а без файлов клиента, — и тогда остаются места прошлой версии. Настоящее число — из пробного прогона ниже, потом из мира.

Замеры джобы мест (время, память, размер файла мест и клеток) — из пробного прогона на Центральной Америке и Австралии с Океанией: _заполняется по прогону_.

## Сборщик на мире

До этого тикета сборщик держал каждый узел дорог по его id в хеш-таблице с координатами, а каждый отрезок — в массивах. Европа заняла 8,6 ГБ (#25), мир (~330 млн узлов) в 15 GiB не поместился бы. Теперь (`data/src/build-graph.ts`):

- Первый проход по путям кладёт id всех узлов дорог в `RepeatedIds` — сортированные куски по 8 байт на id — и находит узлы, на которые ссылаются больше одного раза: развязки.
- Второй проход режет каждый путь на куски: на развязках, на концах, у узла, которого нет в файле, и везде, где граф оставляет узел (соседний узел в другой зоне, оба соседа — один узел, ребро длиннее `MAX_EDGE_SECONDS`, петля). Номер получают только концы кусков.
- `collapse` склеивает куски через пути в рёбра, как раньше склеивал отрезки.
- Зону узла `ZoneCells` берёт по ячейкам 0,05°: в ячейке без границы зоны — один раз на ячейку, в остальных спрашивает `ZoneLocator`. `ZoneLocator` теперь перебирает только кольца, чья рамка накрывает градусную ячейку точки: в мире тысячи колец, больше всего островов.
- Зона берёт те кольца своего отношения, которые выгрузка держит целиком, а кольцо с путём или узлом, которых в выгрузке нет, отбрасывает. Отношение, у которого целы одни дыры, зоны не даёт.

Граф тот же, кроме петель: петлю из узлов степени 2 через несколько путей сборщик режет в другом узле. На Польше так отличаются 33 узла из 128 844, на Германии — 81 из 308 067, число узлов и рёбер то же. Поэтому `ENGINE_VERSION` поднят до 4.

## Набор в R2

Бакет `roadtrip-datasets`:

| Ключ                          | Что                                                              |
| ----------------------------- | ---------------------------------------------------------------- |
| `2026-11-07/graph.graph`      | Граф дорог в формате `engine/src/graph.ts`, 357 МБ               |
| `2026-11-07/zones.json`       | Контуры зон для штриховки (`/data/zones.json` у Worker'а)        |
| `2026-11-07/cities.json`      | Файл городов (`/data/cities.json`)                               |
| `2026-11-07/dataset.json`     | `{ "version": "2026-11-07" }`, как `engine/dataset/dataset.json` |
| `2026-11-07/report.md`        | Отчёт сборки                                                     |
| `<версия>/places.json`        | Файл мест (`/data/places.json`), с #159                          |
| `<версия>/place-outlines.tsv` | Клетки контуров одним файлом (`/data/place-outlines/`), с #159   |
| `2026-11-07/manifest.json`    | Версия, размер и SHA-256 каждого файла                           |
| `current.json`                | Указатель: копия манифеста текущей версии                        |

Указатель переводится, только когда все файлы версии залиты и их размер в бакете сверен (`data/src/publish.ts`), так что упавший прогон оставляет текущей прежнюю версию. Версия, чей манифест уже в бакете, своих файлов не меняет: те же файлы выкладываются снова (перезапуск), другие — отказ до первой заливки, им нужна новая версия. Так же до заливки `publish` отказывает набору мира, где у страны из `COUNTRIES` нет зоны, кроме 35 без зоны на 2026-11-07 (`data/src/zoneless.ts`); пробный прогон этого не проверяет. Деплой (#36) читает `current.json`, берёт файлы из папки его версии и проверяет их по SHA-256. После перевода указателя джоба `publish` запускает сборку `roadtrip` в Workers Builds и ждёт её исхода (`.github/dataset/deploy.sh`, `docs/agents/infrastructure.md`).
